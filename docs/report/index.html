Introduction

Last-mile delivery — the final leg of a shipment from a distribution facility to the end consumer — is the most expensive and operationally complex segment of any urban supply chain. In a city like New York, where traffic density, limited loading zones, and building access constraints compound the challenge, the proximity of warehouse infrastructure to residential population is a critical determinant of delivery cost and service reliability.

This analysis asks a straightforward question: which NYC neighborhoods lack adequate warehouse coverage, and how many people live in those gaps?

To answer it, I combine 2020 Census population data at the census tract level with NYC’s own property tax lot database (PLUTO) to map industrial and warehouse facilities across the five boroughs. I then apply a 1-mile service radius — a conservative threshold chosen to reflect realistic urban delivery reach given NYC traffic and parking constraints — and identify tracts that fall entirely outside that coverage zone.

The 1-mile threshold is intentionally conservative. A 5-mile radius, standard in suburban logistics models, eliminates virtually all gaps in NYC due to the city’s industrial density. The tighter radius surfaces meaningful variation and reflects the operational reality that a warehouse 4 miles away in Manhattan traffic may be effectively unreachable for same-day delivery.

Data Sources

All data is pulled programmatically via public APIs. No manual file downloads are required to reproduce this analysis.

Dataset Source Year Access Method
Census tract boundaries + population U.S. Census Bureau (Decennial Census) 2020 tidycensus R package
Borough boundaries U.S. Census Bureau (TIGER/Line) 2024 tigris R package
Industrial/warehouse tax lots NYC Dept. of City Planning — PLUTO Current NYC Open Data Socrata API

A note on the warehouse data: PLUTO classifies every NYC tax lot by land use code. This analysis filters for code 06 (Industrial & Manufacturing), which includes warehouses, distribution centers, and freight terminals. This is a broader category than warehouses alone — some lots may be light manufacturing or workshops. It represents the best publicly available proxy for logistics infrastructure without purchasing commercial real estate data.

Methodology

The analysis follows four steps:

1. Data acquisition. Census tract population and geometry are pulled from the 2020 Decennial Census via the tidycensus package. Borough boundaries come from the Census TIGER/Line files via tigris. Industrial lot locations are queried from the NYC PLUTO dataset via the Socrata JSON API, then converted to point geometry using the lot centroid coordinates.

2. Coordinate reference system. All layers are projected to EPSG:2263 (New York State Plane, Long Island), which uses feet as its unit of measurement. This CRS is optimized for accuracy in the New York metro area and is the standard used by NYC government GIS data.

3. Buffer analysis. Each industrial lot centroid is buffered by 5,280 feet (1 mile). The resulting circles are dissolved into a single merged coverage polygon using st_union(). This merged polygon represents the total area of NYC within 1 mile of at least one industrial facility.

4. Gap identification. Each census tract is tested for intersection with the coverage polygon using st_intersects(). Tracts with no intersection are classified as underserved — they have no industrial or warehouse facility within 1 mile of their boundaries.

Borough Breakdown

Code 
# Reshape the borough summary for a clean display table.
# We want one row per borough showing both served and underserved counts.
borough_table <- borough_summary |>
  select(borough, coverage, tracts, population) |>
  filter(!is.na(borough)) |>
  tidyr::pivot_wider(
    names_from  = coverage,
    values_from = c(tracts, population),
    values_fill = 0
  ) |>
  mutate(
    pct_underserved = population_Underserved /
                      (population_Served + population_Underserved)
  ) |>
  arrange(desc(pct_underserved)) |>

    Borough             = borough,

    `Served Tracts`      = tracts_Served,
    `Underserved Pop.`   = population_Underserved,
    `% Underserved`      = pct_underserved
  )

Discussion

Key Findings

Manhattan accounts for the largest share of underserved population (111,489 residents), which is initially counterintuitive given the borough’s density and its reputation as a logistics challenge. The explanation lies in land use: Manhattan has very few industrial-zoned lots, and the ones that exist are concentrated in specific corridors like the West Side railyards and the Meatpacking District. Large residential swaths in Upper Manhattan and Washington Heights sit far from any classified industrial facility.

Queens and the Bronx show smaller absolute underserved populations, reflecting their larger industrial footprints along the waterfront and major freight corridors.

Limitations

Land use proxy. PLUTO code 06 captures industrial lots broadly. A more precise analysis would use actual warehouse operating data from a commercial source (CoStar, CBRE) or cross-reference with business license data.

Service radius assumption. The 1-mile radius is a simplification. Actual delivery reach depends on street network connectivity, traffic patterns, and facility operating hours — none of which are captured here. A network-based accessibility analysis using actual road travel times would produce more accurate results.

Population vs. demand. Population density is a proxy for delivery demand. A more complete model would incorporate e-commerce order density, building type (residential vs. commercial), and existing carrier infrastructure.

Supply Chain Implications

For a retailer or third-party logistics provider evaluating NYC market entry or expansion, this analysis suggests that Manhattan above 96th Street and parts of eastern Queens represent underserved markets where a micro- fulfillment center — a small urban warehouse format (10,000–30,000 sq ft) embedded in a mixed-use building — could capture delivery demand that larger facilities in the outer boroughs cannot efficiently serve within a 1-mile radius.
